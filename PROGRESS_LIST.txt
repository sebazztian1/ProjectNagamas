RINGKASAN PERUBAHAN V2
- Barang dipisah menjadi dua jalur: READY STOCK (/ready) dan JASTIP (/jastip).
- Admin membuat JADWAL JASTIP (trip): tanggal buka/tutup PO, negara, estimasi
  tiba, fee, kurs, kuota. Produk jastip terikat ke trip.
- Order dipecah menjadi `orders` + `order_items` (multi-item, ada quantity).
- Status order diperluas sesuai alur jastip; mendukung DP/pelunasan.
- Pembayaran manual: kode unik transfer, batas waktu bayar, riwayat pembayaran.
- Request produk punya alur penawaran (quote) dari admin.
- Notifikasi customer, pengaturan toko, audit log, dan keamanan bukti transfer.

SKEMA DATABASE (MySQL) - VERSI BARU
--------------------------------------------------------------------------------
users
  id, username (unique), password_hash, phone_number, role (customer/admin/staff),
  is_active, created_at, updated_at

categories
  id, name, slug

jastip_trips
  id, title, slug, country, city_or_area, description, terms, cover_image_url,
  currency, exchange_rate, fee_type (percent/flat), fee_value,
  open_date, close_date, departure_date, estimated_arrival_date,
  quota_total (nullable), status (draft/open/closed/purchasing/arrived/
  completed/cancelled), created_by, created_at, updated_at

products
  id, name, slug, description, category_id,
  product_type (ready/jastip), trip_id (nullable, wajib jika jastip),
  price (harga jual rupiah), original_price, original_currency, source_store,
  variants (JSON: ukuran/warna), image_url,
  stock_status (in_stock/out_of_stock), stock_quantity (khusus ready),
  quota (khusus jastip, nullable), max_qty_per_order,
  is_active, deleted_at (soft delete), created_at, updated_at

product_images
  id, product_id, image_url, sort_order

product_requests
  id, user_id, product_name, description, reference_image_url, reference_link,
  trip_id (nullable, trip tujuan jika ada),
  status (pending/reviewed/quoted/accepted/available/rejected),
  quoted_price, quote_note, quote_expires_at, admin_note,
  created_at, updated_at

chat_rooms
  id, customer_id, product_id (nullable), last_message,
  unread_admin_count, unread_customer_count, updated_at
  (unique: customer_id + product_id)

chat_messages
  id, room_id, sender_id, sender_role, message_type (text/image),
  content, image_url, is_read, created_at

orders
  id, order_code (unik, contoh JST-20261002-001), user_id,
  order_type (ready/jastip), trip_id (nullable),
  subtotal, unique_code (3 digit), total_amount,
  payment_type (full/dp), dp_amount, paid_amount, remaining_amount,
  order_status (pending_payment/payment_uploaded/verified/purchasing/arrived/
  ready_pickup/completed/cancelled/expired),
  payment_deadline, fulfillment_method (pickup/shipping),
  shipping_address, shipping_cost, tracking_number (3 kolom terakhir opsional),
  customer_note, admin_note, created_at, updated_at

order_items
  id, order_id, product_id, product_name_snapshot, variant_snapshot,
  qty, price_at_order, subtotal

order_status_logs
  id, order_id, from_status, to_status, changed_by, note, proof_image_url
  (foto struk/bukti pembelian dari admin, opsional), created_at

payments
  id, order_id, payment_kind (dp/full/remaining), bank_account_id,
  sender_name, sender_bank, amount, receipt_url, receipt_hash,
  status (pending/verified/rejected), admin_note,
  verified_by, verified_at, created_at

bank_accounts
  id, bank_name, account_number, account_holder, qris_image_url (opsional),
  is_active

wishlists
  id, user_id, product_id, created_at
  (unique constraint: user_id + product_id)

notifications
  id, user_id, type, title, body, link_url, is_read, created_at

store_settings
  key, value (rekening default, fee default, kurs default, jam operasional,
  status toko buka/tutup, kontak WhatsApp, durasi batas bayar)

audit_logs (opsional)
  id, user_id, action, entity_type, entity_id, detail (JSON), created_at

Catatan relasi penting:
- products.trip_id -> jastip_trips.id (hanya untuk product_type = jastip)
- orders.trip_id -> jastip_trips.id; satu order hanya satu tipe (ready ATAU satu
  trip). Keranjang campur dipecah otomatis menjadi dua order saat checkout.
- Harga jastip = (original_price x exchange_rate) + fee, lalu disimpan sebagai
  `price`; order_items menyimpan snapshot harga saat order.

                              CATATAN TAMBAHAN
================================================================================
- Pengiriman barang secara default tidak disediakan; transaksi diselesaikan lewat
  konfirmasi bukti transfer dan pengambilan mandiri. Opsi pengiriman manual
  (alamat, ongkir input admin, resi) bersifat opsional (Fase 9.5).
- Bukti transfer bersifat sensitif: simpan di bucket private.
- Simpan file ini sebagai acuan berkala. Ubah `[ ]` menjadi `[X]` setiap kali
  tugas selesai diimplementasikan.
- UX Keranjang Campur (Mixed Cart)
    *Di dokumen tertulis bahwa keranjang campur dipecah menjadi dua order saat checkout.
    *Tips: Saat koding nanti, Anda bisa memilih cara yang paling simpel di UI: jika customer sedang memilih barang jastip dari Trip Jepang, lalu ingin menambah barang dari Ready Stock, beri konfirmasi pop-up modal: "Pesanan Ready Stock dan Jastip akan dibuat menjadi tagihan terpisah ya".
- Auto-Expire Batas Waktu Bayar 24 Jam
    *Jika nanti di-deploy ke platform serverless (seperti Vercel) yang tidak punya server background 24 jam terus-menerus, Anda tidak wajib membuat cron job rumit di awal. Cukup buat pengecekan otomatis saat data dipanggil (lazy expiration): jika payment_deadline < NOW() dan status masih pending_payment, otomatis ubah statusnya menjadi expired.
- Penyimpanan Gambar Bukti Transfer:
    *Keputusan menjadikan bucket receipts/ sebagai Private sangat tepat untuk privasi rekening customer. Gunakan fitur Signed URL (URL dengan masa kedaluwarsa, misal aktif 10 menit) saat admin membuka modal verifikasi bukti transfer.
